# Dashboards

Dashboards lets you build custom dashboards by describing them in plain
language to an AI designer. Open it from **Observe > Dashboards** (the page is
titled **Custom dashboards**).

## Browse dashboards

The page lists saved dashboards and your drafts. Each card shows its
visibility (**Organization** or **Private**), title, description, owner and
when it was last updated. Use search to find a dashboard or draft.

## Create a dashboard

1. Click **+ Create dashboard**.
2. Describe what you want to see. The AI designer asks follow-up questions to
   pin down the details.
3. Review the preview, which is built on your own data.
4. Publish the dashboard. Dashboards are either **Private** or shared with
   the **Organization**.

## View and revise a dashboard

Open a dashboard to see its KPI and chart widgets. The header shows the back
link, visibility, owner and number of widgets.

- **Filters**: set the time period and click **Apply filters**.
- **Caveats**: notes on what the data does and does not cover. Read them
  before you share numbers.
- **Revise with AI**: describe a change and the designer updates the
  dashboard.
- **Export** and the more-actions menu for other options.

Dashboard links include `?dashboard=`, so you can share a direct link with
people who have access.

:::tip
For a remembered filter on a list page rather than a full dashboard, use a
saved view. See
[Views, filters and drawers](../get-started/views-filters-and-drawers).
:::
