# Hooks API

**Check tool calls with your own API.** A hook sends each tool call to an HTTPS endpoint you run. Your endpoint answers allow, flag or block: before the tool runs, to stop an action, or after it runs, to stop the AI from seeing the result. Your rules stay on your own server.

Hooks are created and changed only through the Management API. The console lists them read-only under **Settings > AI Gateway > MCP Gateway > Management API > Configured hooks**. Reading hooks needs `read`; creating, changing, deleting and testing them needs `hooks:write` (see [scopes](./management-api#scopes)). Try every call in the [MCP Management API playground](/mcp-gateway-management-playground).

| Stage | When it runs | What your endpoint can do |
| --- | --- | --- |
| `pre_call` | After Quilr's own checks on the call (DLP on the arguments, approvals), before the tool runs. | Allow, flag or block the call. A block means the tool never runs. |
| `post_call` | After the tool runs, before the result goes back to the AI. | Allow, flag or block the result. A block replaces the result with an error; the tool has already run. |

Hooks run on every tool call through the MCP's own endpoint and through [OneMCP](../get-started/onemcp), and on a custom tool's own call. The calls a custom tool's script makes do not run hooks.

## Example {#example}

Block the AI from deleting Jira issues, everywhere:

```bash
curl -X POST https://mcpgateway.quilr.ai/mcpgateway/management/v1/hooks \
  -H "Authorization: Bearer $QUILR_MCP_MANAGEMENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "ACME tool check",
    "stage": "pre_call",
    "endpoint": {
      "url": "https://hooks.example.com/mcp/check",
      "timeout_ms": 1500,
      "on_failure": "block",
      "auth": {"type": "bearer", "secret": "token"},
      "signing": {"secret": "signing_key"}
    },
    "secrets": {"token": "<your token>", "signing_key": "<your signing key>"}
  }'
```

Your endpoint receives every tool call and answers, for example:

```json
{"decision": "block", "user_message": "Deleting issues is not allowed by ACME policy."}
```

## The hook resource {#resource}

| Field | Meaning |
| --- | --- |
| `name` | Required. Up to 200 characters. |
| `description` | Optional. |
| `enabled` | Default `true`. Disabled hooks are kept but never called. |
| `stage` | Required. `pre_call` or `post_call`. |
| `mode` | `enforce` (default): the decision is applied. `observe`: the decision is only recorded; use it to try a new hook safely. |
| `all_mcps` | Default `true`: every MCP. Set `false` and list MCPs in `scope.mcp_ids`. |
| `scope.mcp_ids` | MCP ids (`GET /mcps`) the hook applies to when `all_mcps` is `false`. |
| `scope.tools` | Tool names the hook applies to. Empty means every tool. On OneMCP, the MCP's own tool name. |
| `endpoint.url` | Required. A public `https` address. No user information in the URL, no fragment. |
| `endpoint.timeout_ms` | 100 to 10000, default 1500. |
| `endpoint.on_failure` | `allow` (default) or `block`: what happens when your endpoint does not answer properly. |
| `endpoint.auth` | `{"type": "none"}` (default), `bearer` (`secret`), `basic` (`username_secret`, `password_secret`) or `api_key` (`header`, `secret`). Values are secret names. |
| `endpoint.signing` | `{"secret": "<name>"}` to sign every call (see [Verify calls](#signing)). |
| `send` | `arguments`, `result`, `user`: each `true` by default. Set one to `false` to leave the tool arguments, the result (on `post_call`) or the user's email out of the call. |
| `secrets` | Secret values by name, for example `{"token": "..."}`. Write only. |

**Secrets.** Secret values are encrypted and never returned: reads show `********`. On `PATCH`, send `********` to keep a value, a new value to rotate it, or `null` to remove it; leave `secrets` out to keep them all. Every secret must be used by `auth` or `signing`.

`PATCH` merges the top-level fields you send over the hook. `PATCH` and `DELETE` need `If-Match` with the hook's `version`.

## What your endpoint receives {#request}

A `POST` with JSON:

```json
{
  "version": "1",
  "hook": "hook_3f2a9c0b1d4e5f6a7b8c",
  "stage": "pre_call",
  "request_id": "0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e",
  "tenant_id": "tenant-123",
  "timestamp": "2026-11-17T10:00:00.00Z",
  "mcp": {"id": "a1b2c3d4", "name": "Jira Cloud"},
  "tool": {"name": "delete_issue"},
  "arguments": {"issue_key": "OPS-42"},
  "user": {"email": "dana@example.com"}
}
```

On `post_call` it also carries `result`: the tool's `content`, `isError` and `structuredContent`. `request_id` is the same for the `pre_call` and `post_call` of one tool call. A test call (`POST /hooks/{hook_id}/test`) carries `"test": true` and sample values.

## What your endpoint returns {#reply}

Answer `2xx` with JSON:

| Field | Meaning |
| --- | --- |
| `decision` | Required. `allow`, `flag` (continue, and record the flag) or `block`. |
| `reason` | Recorded with the call (up to 1000 characters). Never shown to the AI. |
| `user_message` | Shown as the tool's error when the call is blocked. Without it: "This tool call was blocked by your organization's tool-call check." |
| `labels` | Up to 20 strings, recorded with the call. |
| `metadata` | JSON, recorded with the call. |

The reply can be at most 64 KB. A non-`2xx` status, a body that is not JSON, or a missing or unknown `decision` is a failure.

**Several hooks.** Hooks on the same stage run in parallel. The strictest `enforce` decision wins (`block` over `flag` over `allow`). `observe` hooks never change the call.

**What the AI sees on a block.** The tool call returns an error result (`isError: true`) whose text is your `user_message`. Every call records each hook that ran: hook id, name, stage, mode, decision, latency, the HTTP status, and an error code or your `reason` and `labels`.

## Timeouts and failures {#failures}

A call fails on a timeout, a connection error, a non-`2xx` or unreadable reply, a reply over 64 KB, or a destination the gateway does not call. Then `endpoint.on_failure` applies: `allow` lets the call continue, `block` stops it.

**Circuit breaker.** After 5 failures in a row, the hook is skipped for 30 seconds and its `on_failure` applies without a call.

## Verify calls {#signing}

With `endpoint.signing`, every call carries `X-Quilr-Signature: t=<unix seconds>,v1=<hex>`, where the hex value is the HMAC-SHA256 of `<t>.` followed by the raw body, keyed with your signing secret. Recompute it and compare, and reject old timestamps:

```python
import hashlib, hmac, time

def verify(header: str, body: bytes, secret: str, max_age: int = 300) -> bool:
    parts = dict(item.split("=", 1) for item in header.split(","))
    if abs(time.time() - int(parts["t"])) > max_age:
        return False
    expected = hmac.new(secret.encode(), f"{parts['t']}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts["v1"])
```

## Security {#security}

- The URL must be a public `https` address. Quilr addresses and private or local addresses are refused when you save (`400 blocked_destination`) and again when the gateway connects. Redirects are not followed.
- Secret values are encrypted at rest, sent only in headers, and never returned.
- Turn off `send.arguments`, `send.result` or `send.user` to keep that data off your endpoint.

## Test a hook {#test}

`POST /hooks/{hook_id}/test` sends a sample call for the hook's stage to your endpoint (with `"test": true`, a sample tool, and a sample result on `post_call`), whether the hook is enabled or not, and returns `ok`, `status_code`, `ms`, `error` and your `reply` as the gateway read it. Use it after creating a hook and after rotating secrets.

## Limits {#limits}

| Limit | Value |
| --- | --- |
| Hooks per organization | 10 |
| Enabled `enforce` hooks per stage | 3 |
| Timeout | 100 to 10000 ms (default 1500) |
| Reply size | 64 KB |
| Secrets per hook | 8 |

Going over a limit is `422 hook_limit`.

## Errors {#errors}

| Status | Code | Meaning |
| --- | --- | --- |
| 400 | `invalid_request` | A field is missing or invalid; `fields` names it. |
| 400 | `blocked_destination` | The URL is not a public `https` address the gateway calls. |
| 400 | `unknown_secret` | `auth` or `signing` names a secret not sent under `secrets`. |
| 403 | `insufficient_scope` | The key lacks `hooks:write` (writes and tests) or `read`. |
| 404 | `not_found` | No hook with that id in your organization. |
| 412 | `version_conflict` | The hook changed since you read it; read it again and retry. |
| 422 | `hook_limit` | See [Limits](#limits). |
| 428 | `precondition_required` | `PATCH` or `DELETE` without `If-Match`. |
