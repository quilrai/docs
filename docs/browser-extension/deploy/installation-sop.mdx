# Browser Extension installation SOP

The installation SOP is the operator runbook for rolling the Browser Extension and its native Browser Agent out to Chrome, Edge and Safari on macOS and Windows. Work through the steps in order: each one gates the next. At the top of each step, pick your platform and your tenant environment, and the commands and hostnames on the page change to match.

<InstallSop track="browser-extension" />

## What each step covers

| Step | Use it to |
| --- | --- |
| <SopLink track="browser-extension" step="prerequisites">Prerequisites</SopLink> | Check the tenant, supported browsers and OS versions, admin access, the network allow-list and the packages. |
| <SopLink track="browser-extension" step="prerequisites-validation">Prerequisites validation</SopLink> | Confirm the QuilrAI hosts are reachable before you install. |
| <SopLink track="browser-extension" step="manual-installation">Manual installation</SopLink> and <SopLink track="browser-extension" step="validation-manual-installation">validation</SopLink> | Install on one device, then prove the extension and the Browser Agent work. |
| <SopLink track="browser-extension" step="installing-using-mdm">Installing using MDM</SopLink> | Roll out with Microsoft Intune, Jamf Pro, Kandji, ManageEngine Endpoint Central or SCCM. |
| <SopLink track="browser-extension" step="verify-mdm-install">Verify MDM install</SopLink> | Confirm the fleet rollout on the devices and in the console. |
| <SopLink track="browser-extension" step="troubleshooting">Troubleshooting</SopLink> | Triage failures and collect what QuilrAI support needs. |
